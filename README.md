# ALVIE Spiral – Wiskundige onderbouwing

Deze repository bevat de wiskundige onderbouwing van het ALVIE-spiraalvenster.

## Bestanden
- `ALVIE_SPIRAL_PRINCIPLE_MANIFESTO.py` – het wiskundig manifest (uitvoerbaar Python)
- `sacks_spiraal_analyse.py` – statistische analyse van priemgetalclustering in de Sacks-spiraal
- `sacks_syntropie_entropie.py` – analyse van de 3-6-9 triade als syntropie/entropie model
- `deepseek_markdown_20260811_77341e.md` – AI-gegenereerde toelichting (zie bestand)

## Gebruik
Draai de Python-scripts om de analyse uit te voeren en visualisaties te genereren.

```bash
python sacks_spiraal_analyse.py
python sacks_syntropie_entropie.py
python ALVIE_SPIRAL_PRINCIPLE_MANIFESTO.py
```

## Inhoud
De repository bevat uitsluitend zuivere wiskunde:
- Priemgetalverdeling en clustering in de Sacks-spiraal
- Digitale wortelanalyse (3-6-9 patroon)
- Chi-kwadraattoetsen en binomiale toetsen voor significantie

## Symbolische cyclus 3 → 6 → 9
Binnen dit model representeert 3 de start, 6 de transitie en 9 de afronding van een periodieke cyclus.
