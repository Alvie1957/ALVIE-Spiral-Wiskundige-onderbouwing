# ALVIE Spiral – Wiskundige onderbouwing

Deze repository bevat de wiskundige onderbouwing van het ALVIE-spiraalvenster.

## Bestanden
- `wiskundige_onderbouwing.md` – de volledige wiskundige tekst
- `sacks_spiraal.py` – Python-code voor de Sacks-spiraal

## Gebruik
Bekijk de wiskundige tekst in `wiskundige_onderbouwing.md`. Draai de code om de spiraal zelf te genereren.

## Symbolische cyclus 3 → 6 → 9
Binnen dit model representeert 3 de start, 6 de transitie en 9 de afronding van een periodieke cyclus.

*Dit is de wiskundige laag – de metafysische laag is apart beschikbaar.*
